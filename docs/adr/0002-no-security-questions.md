# ADR 0002：不使用安全问题，采用一次性恢复密钥

## 状态

已接受

## 背景

用户希望忘记主密码后仍能恢复使用。安全问题答案通常短、可猜测或可从公开信息推断，会削弱主密码带来的保护。

## 决策

不提供安全问题恢复。创建保险库时生成高熵的一次性恢复密钥，仅展示给用户并提示离线备份。恢复流程使用恢复密钥验证用户并允许设置新主密码。用户自定义问题或个人信息答案不参与恢复。

## 后果

- 正面：避免引入弱口令恢复入口；不需要服务端身份系统。
- 代价：恢复密钥丢失时，保险库仍不可恢复。
- 产品要求：首次创建和导出流程必须清楚提示用户备份恢复密钥，且恢复密钥不能以明文写入扩展存储。
