# Strong Password Vault

一个默认使用简体中文的 Chrome 和 Microsoft Edge Manifest V3 浏览器插件：使用浏览器密码学 API 生成强密码，并将凭据保存在本机加密保险库中。

## 当前能力

- 默认生成 24 位、包含大小写/数字/符号的密码
- PBKDF2-SHA-256（600,000 次迭代）派生密钥，AES-256-GCM 加密保险库
- 主密码不落盘；使用一次性随机恢复密钥重设主密码
- 密码条目包含名称、完整 origin、用户名、密码和备注
- 点击扩展后自动识别当前网站：未保存时一键生成、保存并填充；已保存时直接显示匹配条目
- 使用浏览器侧边栏打开，点击页面其他位置时不会自动隐藏
- 自动读取当前活动标签页的 HTTPS origin；当浏览器无法提供当前页面地址时，才显示手动输入备用入口
- 只允许用户主动触发、且严格匹配完整 origin 的自动填充
- 加密 JSON 备份的导出与导入
- 解锁后在本次浏览器会话内保持可用；闲置 15 分钟、浏览器重启或主动锁定后需要重新输入主密码
- 复制密码后 30 秒尝试清理剪贴板（浏览器权限和弹窗关闭可能使清理无法执行）
- 仅在用户主动点击填充时临时注入当前页面，不常驻读取所有网站

## 在 Chrome / Edge 中加载

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目目录。
4. 固定扩展后点击工具栏图标，首次使用创建保险库并离线备份恢复密钥。
5. 点击工具栏中的扩展图标打开侧边栏；扩展会自动识别当前网站，然后生成并保存密码。侧边栏可以保持打开，切换页面内容不会关闭它。

## 开发验证

```bash
npm test
```

这是安全敏感的软件，当前版本尚未完成独立安全审计。建议仍先用于低风险网站，不要保存银行、交易所或主邮箱等关键凭据。
